# 字段补齐与下游导出验收

日期：2026-11-24。范围：为日线补齐昨收、停牌、ST、复权因子和涨跌停价，并导出到 quant-research-lab 与 alpha-evidence-lab。全市场历史股票池、PIT 财务和完整 A 股撮合仍未完成。

## 数据来源与规则

- BaoStock 0.9.4：不复权与后复权日线、preclose、tradestatus、isST、交易日历、证券基础资料（含退市）。
- 实测核对：600518.SH 于2019-05-21变为ST且当日跌4.97%（5%规则）；300104.SZ 停牌日为显式行（价格=停牌前收盘、成交量0或空）；600000.SH 2023-07-21除权日昨收7.10（前收盘7.42）；与已缓存的 AKShare 600000.SH 2024-01-02至05 开高低收完全一致。
- 涨跌停规则表与来源见 `quant_agent/data/rules.py` 和 `docs/data_coverage.md`。

## 下游运行

- quant-research-lab：`research` 读入导出数据，57个滚动测试段、171次候选评估；开盘涨停阻断买入3次，无"涨跌停未知"阻断。默认配置下回撤熔断于2021-04-13触发后904个交易日空仓，报告已提示；`drawdown_reset=next_fold` 时样本外累计 -3.11%、基线 +9.29%、成本占起始资金18.3%。简单动量规则在该样本上没有证据优势。
- alpha-evidence-lab：6只股票（300104.SZ 交易日不足450未纳入）、5个episode、3种方法、270次尝试；random 与 memory 相对 ordered 的Bonferroni校正p值为0.543与1.0，均未晋级；`alpha-lab verify` 通过。导出说明已注明同一市场股票相关、不是独立路径。
