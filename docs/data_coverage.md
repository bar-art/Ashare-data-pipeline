# 数据覆盖清单（第一阶段）

核对日期：2026-11-19。用户同意先验收框架、小样本和透明缺口。

| 数据 | 当前实现 | 缺口与处理 |
|---|---|---|
| 不复权日线 | AKShare 东方财富接口，按代码和日期请求 | 单票可用性依赖上游；不声明覆盖全部退市股 |
| 成交量、成交额 | 手乘100转换为股；金额保留人民币元 | 仅对应东方财富日线，不泛化至其他接口 |
| 交易日历 | 新浪接口，缓存实际返回日期 | 官方页面范围说明和示例年份冲突；超出返回首末日期报警，不补工作日 |
| 当前股票名单 | AKShare 当前代码名称快照 | 不含完整上市/退市历史；禁止作为历史股票池 |
| pre_close、复权因子 | BaoStock：preclose 为交易所除权参考价；复权因子 = 后复权收盘/不复权收盘 | AKShare 仍为空；仍不用 close.shift 或涨跌额猜测 |
| 历史ST、停牌 | BaoStock 逐日 isST、tradestatus（停牌日为显式行） | AKShare 仍为空；不用当前ST回填，不把缺失行情当停牌 |
| 涨跌停价 | 由昨收按已核验规则计算，逐日用实际高低价校验（`rules.py`） | 规则外情形留空且不豁免；北交所无来源 |
| Yahoo 交叉核对（默认） | `crosscheck`：原始价、停牌、公司行动日期、用其高低价检验涨跌停规则 | 只核对不合并；深市2020年1-5月及个别日期存在 Yahoo 数据错误；不含北交所 |
| Tushare 交叉核对（可选） | `crosscheck`：daily、stk_limit（2007起，含北交所）、suspend_d（2000起） | 只核对不合并；来源说明记录接口主机 |
| 上市/退市日期 | BaoStock 证券基础资料（含已退市） | 用于新股豁免和缺失交易日判断；不是历史指数成分 |
| 完整退市历史、历史指数成分、行业历史、公告日财务、估值 | 尚未实现 | 第二阶段起扩展，未完成前不发布完整回测结论 |
| Tushare/BaoStock | 后续适配器位置已预留 | 第一阶段不实现、不自动回退，以免混淆口径 |

所有缓存保留提供方、来源接口、抓取时间、请求区间、行数、SHA256。抓取时间不是公告日，不证明 PIT。质量报告中的缺失交易日是待解释项，不自动认定接口丢数。缓存刷新使用 `--refresh`；空响应不记为覆盖成功。当前日和未来日期禁止请求，避免把未完成日线缓存为完成数据。

本地缓存为单进程写入设计；不提供并发写入支持。正常缓存命中不访问行情接口；日历和证券名单快照需显式刷新。新版 AKShare 通过统一 HTTP 客户端配置连接/读取超时，本项目设置该超时；旧版日线接口如支持 timeout 参数则直接传入。读取超时不是整条命令的总时长上限。

## 一手来源

- [AKShare 官方日线文档](https://akshare.akfamily.xyz/data/stock/stock_quote.html)：`stock_zh_a_hist_em`，不复权 `adjust=""`，成交量单位手，金额元。
- [AKShare 官方交易日历](https://akshare.akfamily.xyz/data/calendar/calendar.html)：新版 `calendar_trade_date_hist_sina`，只承认实际返回范围。
- [AKShare 官方证券名单源代码](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_info.py)：当前名单与退市名单为不同接口；本阶段未合并退市资料。
- [BaoStock](https://pypi.org/project/baostock/)：`query_history_k_data_plus` 字段 preclose/tradestatus/isST，adjustflag 1=后复权、3=不复权；本项目对600518、300104、600000的停牌、ST切换和除权日做了实测核对。
- 涨跌停规则：主板注册制新股前5日不设涨跌幅，自2023-04-10首批主板注册制新股上市起施行（[中国证券网](https://cs.com.cn/xwzx/hg/202302/t20230202_6321277.html)、[虎嗅](https://m.huxiu.com/article/1118866.html)）；沪深主板风险警示股票涨跌幅自2026-07-06起由5%调整为10%（[东方财富](https://finance.eastmoney.com/a/202607053794287472.html)、[东方财富](https://finance.eastmoney.com/a/202607033793555228.html)）。均为新闻转述，正式规则以交易所发布文本为准。
- [财政部、税务总局2023年第39号公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html)：2023-08-28 起印花税减半。其余规则仍是配置草案，第二阶段逐项核验，不能视为2026年完整交易规则确认。

仅供研究，不构成投资建议。
